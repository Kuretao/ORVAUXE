# Accessibility Standard

Target WCAG 2.2 AA. Source: [W3C WCAG 2.2](https://www.w3.org/TR/WCAG22/).

- Semantic headings and landmarks.
- Full keyboard operation and logical focus order.
- Visible focus with sufficient non-text contrast.
- Normal text contrast at least 4.5:1; qualifying large text at least 3:1.
- Labels, descriptions and programmatically associated errors for forms.
- Status and success messages announced when appropriate.
- Alternative text written for purpose; decorative images use empty alt.
- Touch targets and controls sized for reliable operation.
- `prefers-reduced-motion` respected; no required information exists only inside animation.
- Screen-reader names for icon-only controls.
- Zoom and reflow tested.

Accessibility defects in navigation, lead form or primary content block launch.
