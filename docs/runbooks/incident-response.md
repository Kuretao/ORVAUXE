# Incident Response — Small-Team Baseline

## Severity

- SEV-1: site unavailable, secret/PII exposure, or lead path fully broken.
- SEV-2: major route or integration degraded with workaround.
- SEV-3: localized visual/content defect without material business interruption.

## Flow

Detect → assign incident owner → contain → communicate internally → recover → verify → document. Preserve useful logs without copying sensitive data into chat or analytics. Every SEV-1/2 receives a short retrospective and an owned prevention action.
