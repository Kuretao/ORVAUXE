# ORVAUXE Analytics

Analytics is a versioned product contract. The event dictionary is the source of truth; implementation will later expose typed functions rather than scattered `posthog.capture(...)` calls.

PostHog owns web behavior. Attio owns qualification and sales stages. Direct personal details from project forms are not analytics properties.

Documents:

- `tracking-plan.md` — scope and implementation rules.
- `event-dictionary.md` — event contract.
- `funnel-definitions.md` — behavioral and sales funnels.
- `privacy.md` — classification and restrictions.
