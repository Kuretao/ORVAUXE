# Metadata Rules

## Titles

- Unique and descriptive.
- Prefer roughly 45–60 characters as an editorial working range, not a hard ranking rule.
- Put the main page concept before `— ORVAUXE` where possible.

Templates:

```text
Home: Premium Shopify Storefronts — ORVAUXE
Edition: {Edition Name} — Premium Shopify Edition | ORVAUXE
Atelier: Bespoke Shopify Design & Development — ORVAUXE
Studio: Independent Commerce Atelier — ORVAUXE
```

## Descriptions

Write 140–160 character working drafts that describe audience, offer and differentiator. They are click-oriented summaries, not keyword storage.

## Headings

- One primary H1 that names the page subject.
- H2/H3 hierarchy follows content structure, not visual size.
- The logo is not the H1 by default.

## Canonicals and social

- Self-canonicalize indexable pages.
- Canonical targets return 200 and are included in the sitemap.
- Generate Open Graph title, description and 1200×630 image with readable safe zones.
- Use absolute production URLs for metadata assets.

Next.js supports static metadata, `generateMetadata` and special files for social images, robots and sitemap: [Next.js metadata documentation](https://nextjs.org/docs/app/getting-started/metadata-and-og-images).

## Images and links

Alt text describes the image’s purpose in context. Decorative editorial texture uses empty alt. Internal link labels describe the destination; avoid repeated “learn more”.
