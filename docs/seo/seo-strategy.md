# ORVAUXE SEO Strategy v1.0

## Principle

SEO is an architecture and content contract. Elegant copy remains possible when each page has a clear search purpose, a descriptive title, semantic headings, crawlable primary text and deliberate internal links.

## Launch routes

```text
/
/editions
/editions/[slug]
/atelier
/studio
/start-a-project
```

Do not publish empty `/work` or `/journal` sections. Add them when they contain useful evidence or editorial content.

## Page intent

- Home: brand + premium commerce studio category.
- Editions index: productized premium Shopify storefront systems.
- Edition detail: a specific Edition, category fit, scope, starting price and launch estimate.
- Atelier: bespoke and semi-custom commerce design/development.
- Studio: trust, point of view, process and international operating model.
- Start a Project: qualified lead conversion.

## Language coexistence

Use a poetic hero line, then plain-language supporting copy. Put category and service terms into titles, introduction, headings, internal links, FAQs and image alternatives where natural. Never repeat awkward keyword variants to manufacture density.

## Technical baseline

- Server-render primary copy and links.
- Generate metadata at route level.
- One canonical URL policy.
- XML sitemap containing indexable canonical URLs.
- Robots rules for crawling, not as a substitute for `noindex`.
- Useful 404, explicit redirect map and no redirect chains.
- JSON-LD only when visible content supports it.
- Search Console and URL inspection after launch.

Google recommends absolute canonical URLs in sitemaps and explains that robots.txt should not be used as an indexing control: [Google Search sitemap](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap) and [technical SEO guidance](https://developers.google.com/search/docs/fundamentals/get-started).
